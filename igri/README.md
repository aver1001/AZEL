# IGRI 이그리

버려진 담배꽁초에서 태어난 불의 정령 **이그리**가 되어, 숲을 시작으로 도시까지 모든 것을 집어삼키는 재앙으로 성장하는 탑다운 액션 로그라이크 + .io 게임입니다. 기획서의 핵심 시스템을 three.js 프로토타입으로 구현했습니다. 빌드 과정 없이 정적 파일만으로 돌아갑니다.

## 실행

ES 모듈을 쓰기 때문에 `index.html`을 파일로 바로 열면 동작하지 않습니다. 정적 서버로 여세요.

```bash
cd igri
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

GitHub Pages에 올리면 `…/igri/` 경로에서 바로 플레이할 수 있습니다. three.js는 jsDelivr CDN(0.170.0)에서 불러옵니다.

더블클릭으로 여는 단일 HTML이 필요하면(itch.io 업로드, Electron/Tauri 래핑 등) three.js까지 한 파일로 묶을 수 있습니다.

```bash
cd igri
npm i --no-save esbuild three@0.170.0
node tools/build-single.mjs   # dist/igri.html 생성
```

## 기획서 → 구현 대응

- **연소 스노우볼링(.io)** — 크기(연료) = 체력 = 공격력. 반경 `r = 0.25·√mass`. 자신보다 연소 등급이 낮은 물체에 닿으면 태우고 연료를 얻고, 큰 물체에 부딪히거나 물에 닿으면 작아집니다. 가만히 있어도 연료가 계속 줄어듭니다. (`js/player.js`, `js/config.js`의 `MASS`, `OBJECTS`)
- **티어 4단계** — 불씨(매크로 카메라 + 틸트시프트) → 모닥불(탑다운) → 들불(줌아웃) → 재앙(위성 뷰). 티어별 가연물과 천적이 표 그대로 배치되어 있습니다.
- **로그라이크 스킬** — 가스통·불법 폐기물·송전탑·주유소·유조 탱크·소방차 엔진룸을 터뜨리면 3지선다로 진화합니다. 기획서의 바람(이동+잔불)·기름(주기적 광역 폭발)·불티(유도 불씨)에 열기·숯불·화염 회오리·플래시오버를 더해 7종, 각 5레벨입니다.
- **지명 수배(GTA식)** — 피해액이 커질수록 ★이 오르고 소방관(소화기) → 소방차(물대포, 후방 엔진룸 타격 시 폭발) → 소방 헬기(붉은 지연제 투하, 방화수 낙하)가 투입됩니다. 지연제가 뿌려진 땅과 물체는 절대 타지 않습니다.
- **기상 과학** — 불씨 단계의 빗방울(예고 그림자)·이슬·작은 동물, 모닥불 단계의 웅덩이·소나기, 들불 이후의 국지성 호우와 폭풍우. 들불 이상이거나 한꺼번에 많이 태우면 **상승 기류**가 먹구름을 밀어내고, 빗속을 뚫으면 생기는 **수증기 은폐**가 소방대의 조준을 흐트러뜨립니다.
- **보스: 물의 정령** — 재앙 단계에 도달하면 도시 저수지에서 깨어납니다. 링·조준·나선 탄막, 예고 후 발사되는 물대포, 체력 절반 이하에서는 해일. 물대포가 닿는 순간 대쉬하면 **증발 패링**으로 수증기 폭발 피해를 줍니다.
- **엔딩(반전)** — 꺼지거나, 시간이 다 되거나, 보스를 쓰러뜨리면 피해 영수증(소실 면적, 태운 나무, 잃어버린 야생동물 보금자리, 불탄 건물·차량, 대피 주민, 투입 소방 인력, 총 재산 피해액)을 출력한 뒤, 소리를 끊고 흑백으로 전환해 여운을 남기고 "이 모든 시작은 작은 담배꽁초 하나였습니다." 문구 후 타이틀로 돌아갑니다.

## 재미 요소 (플레이 루프)

- **흡입 연출** — 자기보다 확실히 작은 것은 제자리에서 타는 대신 이그리에게 빨려 들어가며 번쩍 사라집니다. 먹을 때마다 콤보에 맞춰 음이 올라가는 효과음이 납니다.
- **연소 콤보** — 1.9초 안에 계속 태우면 콤보가 이어지고 연료 보너스가 최대 +30%까지 붙습니다. 끊기는 순간 콤보만큼 연료를 한 번에 정산합니다. 10·25·50·100·200 콤보마다 연출이 나옵니다.
- **화염 폭주(피버)** — 연달아 태우면 게이지가 차고, 가득 차면 7초 동안 빨라지고 15% 더 큰 것까지 먹으며 주변 가연물을 저절로 빨아들입니다.
- **티어업 노바** — 단계가 오르는 순간 충격파가 주변을 한꺼번에 불태우고, 잠깐의 슬로모션과 무적 시간이 주어집니다.
- **의뢰** — 캠핑장 텐트, LPG 가스통, 소방관, 송전탑, 소방차 엔진룸, 주유소, 헬기, 랜드마크, 물의 정령까지 맵에 있는 요소를 순서대로 목표로 제시합니다. 보상은 새로운 힘·연료·제한 시간입니다.
- **긴급 과제** — 1분 남짓마다 "15초 안에 N개", "콤보 N", "나무 N그루" 같은 시간 제한 과제가 뜹니다. 성공하면 연료와 폭주 게이지를 받습니다.
- **강풍 특보** — 모닥불 단계부터 가끔 돌풍이 불어 불길이 바람 방향으로 크게 번지고, 바람을 타면 이동이 빨라집니다. 가까이서 번진 불은 연료 일부로 돌아옵니다.
- **대쉬 연소** — 고열 방출 중에는 조금 더 큰 것도 태우고 소방관을 쫓아낼 수 있습니다.
- **마지막 불씨** — 한 판에 한 번, 꺼지는 순간 작은 불씨로 되살아납니다.
- **최고 기록** — 피해액·최고 단계·최대 콤보를 타이틀에 보여줍니다(브라우저 저장소).

수치는 모두 `js/config.js`의 `COMBO`, `FEVER`, `MISSIONS`, `CHALLENGES`, `WIND`에 있습니다.

## 캐릭터 리그와 모션 (UniMate)

사람과 동물은 스킨드 메시 골격(`js/models/rigs.js`)으로 다시 만들었고, 상태와 실제 이동 속도에 맞춰 모션 클립을 골라 재생합니다(걷기/달리기/패닉/소화기 조준, 깡충/질주, 풀 뜯기, 날갯짓 …). 모닥불 단계에는 불을 피해 달아나는 **사슴**, 불씨 단계부터는 다가가면 날아오르는 **새 떼**가 추가되었습니다(날기 직전에 대쉬로 잡을 수 있음).

골격은 텍스트→모션 모델 [UniMate](https://github.com/Friedrich-M/UniMate)가 그대로 받을 수 있는 형태입니다. `tools/unimate/`로 골격을 UniMate 형식으로 내보내고, 생성된 모션을 게임 클립(`js/models/clips/unimate.js`)으로 변환합니다. 생성 결과가 없으면 손으로 키잉한 기본 동작이 재생됩니다. 자세한 순서는 [`tools/unimate/README.md`](tools/unimate/README.md), 확인은 `rigs.html`.

## 실제 산불 사진 넣기

엔딩의 흑백 실사 컷인은 저작권 때문에 사진을 포함하지 않았습니다. 사용 허락을 받은(또는 퍼블릭 도메인) 사진을 `assets/ending/`에 넣고 `js/config.js`의 `ENDING.photos`에 경로를 적으세요.

```js
photos: ['assets/ending/photo1.jpg', 'assets/ending/photo2.jpg'],
```

사진이 없으면 플레이어가 방금 태운 맵을 흑백으로 비추는 장면이 대신 나옵니다.

## 구조

```
igri/
  index.html          게임 셸, HUD, 오버레이
  css/style.css
  models.html         모든 절차적 모델 카탈로그(vibe3d식 미리보기)
  rigs.html           리그 뷰어: 캐릭터별 모션 클립 재생, 뼈대 표시
  dev.html            월드 뷰어 (?x=&z=&r=&burn= 로 원하는 지점을 렌더)
  tools/build-single.mjs  단일 HTML 번들 빌드
  tools/unimate/      UniMate 브리지(리그 내보내기, 변환·왕복 검증, 생성 모션 → 게임 클립)
  js/
    config.js         밸런스 수치 전부(티어, 가연물, 피해량, 수배 단계, 스킬)
    main.js           부팅, 상태 머신(타이틀→인트로→플레이→스킬 선택→엔딩), 프레임 루프
    render.js         렌더러, 블룸·그레이딩·틸트시프트·흑백, 티어 카메라, 대기(연기·폭풍)
    player.js         이그리: 이동, 대쉬/패링, 흡수·충돌, 연료 감소, 7개 스킬
    enemies.js        동물(토끼·다람쥐·사슴·새), 주민, 소방관, 소방차, 소방 헬기
    weather.js        빗방울, 이슬, 웅덩이, 비 구역, 상승 기류, 수증기
    boss.js           물의 정령과 탄막, 물대포, 해일
    missions.js       의뢰 체인과 긴급 과제
    hud.js            HUD, 미니맵, 토스트, 스킬 카드
    ending.js         피해 영수증과 엔딩 연출
    audio.js          WebAudio 합성 효과음과 BGM (오디오 파일 없음)
    input.js          키보드·마우스·게임패드
    world/layout.js   절차적 맵(숲→시골→강→교외→도시), 도로·물 마스크, 배치
    world/objects.js  인스턴스 가연물, 연소·확산·진화·지연제, 공간 해시, 투시 컷아웃
    world/burnmap.js  GPU 그을음 맵(탄화·열기·지연제) + CPU 격자(미니맵·통계)
    world/terrain.js  지형, 물, 하늘
    fx/               불꽃 빌보드, 파티클, 폭발
    models/           낙엽부터 초고층 빌딩·소방차까지 절차적 로우폴리 모델
    models/rigs.js    사람·동물 스킨드 리그 (UniMate 호환 관절 이름, 항등 휴식 회전)
    models/motion.js  모션 클립 데이터 ↔ three.js AnimationClip, 상태별 애니메이터
    models/clips/     손 키잉 기본 동작 + UniMate 생성 동작
```

모델은 [vibe3d](https://github.com/vibe-stack/vibe3d)처럼 소스 코드 자체가 모델입니다. `js/models/catalog.js`의 함수 하나가 모델 하나이고, 수정 후 `models.html`에서 바로 확인할 수 있습니다.
